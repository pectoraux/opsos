## Decisions (key)
- Governance module depends ONLY on `@kernel/shared-kernel` (for `RuntimeClock` type + `hashSeed`). NO imports from any other kernel module — the framework references artifacts by type/kind strings, not by importing other kernel modules.
- Internal `infrastructure/semver.ts` mirrors `protocol-sdk/validation/versioning.ts` (parse, compare, satisfiesRange) — pure, no I/O, no Date.now/Math.random. Added `compareSemverStrings` (string-in, string-in) for the registry's `listVersions` sort.
- Plan/certification ids are DETERMINISTIC: `mig-${type}-${hashSeed(type|from|to).toString(16)}` and `cert-${kind}-${hashSeed(kind|subjectId|subjectVersion).toString(16)}`. Same inputs → same ids, byte-identical across runs.
- Lifecycle legal transitions encode the OpsOS evolution contract: `experimental → {experimental, preview, retired}`, `preview → {preview, stable, retired}`, `stable → {stable, deprecated}`, `deprecated → {deprecated, retired}`, `retired → {retired}`. Self-transitions always allowed (re-declaration). Notably `stable → retired` is FORBIDDEN — must pass through `deprecated` first (the platform's Kubernetes-style deprecation policy).
- `DefaultCompatibilityEngine` rule: `compatible = majorCompatible && rangeSatisfied`. `majorCompatible = source.major === target.major`. `rangeSatisfied = true` when no declared range for the target kind (the framework does NOT invent incompatibilities). When a range IS declared on the source for the target kind, the target version must satisfy it. `minorCompatible = majorCompatible && source.minor <= target.minor` (informational — does not gate the headline boolean; captures "source may use features from target.minor=X"). Reports are explainable: dimension + sourceVersion + targetVersion + majorCompatible + minorCompatible + rangeSatisfied + one-line details string.
- `DefaultMigrationEngine`: 5 plan builders (upgrade, downgrade, rollback, staged-rollout, canary) each with a fixed sequence of named steps (snapshot, pre-check, compatibility-check, apply, apply-1pct/10pct/50pct/100pct, deploy-canary, monitor, promote, revert, verify, cleanup). `estimatedDurationMs` is a fixed per-action-kind constant (NOT wall-clock — deterministic core never calls Date.now). `dryRun` and `execute` both produce deterministic `MigrationResult` (in-memory `execute` is a no-side-effect simulation; production engines wrap real artifact managers). `rollbackPlan` is the deterministic id of the reverse migration.
- `DefaultCertificationEngine`: takes an injected `RuntimeClock` (default: zero clock returning 0). `certify` stamps `certifiedAt = clock.now()`, status `"certified"`. `verify` returns the most-recent non-revoked, non-expired cert (sorted by certifiedAt desc, id asc for stable tie-break). Expiry is lazy: `verify`/`list` calls scan the store and update `status → "expired"` for any cert past its `expiresAt` (revoked is terminal and overrides expiry). `revoke` is idempotent.
- `InMemoryGovernanceRegistry` exposes TWO extension methods beyond the public `GovernanceRegistry` port — `recordMigration(artifactId, from, to, at, type)` and `recordCompatibility(artifactId, sourceVersion, target, compatible, at)` — which the application use-cases (`plan-migration` execute path, `check-compatibility`) call to feed runtime events into the registry so `getEvolutionHistory` can surface them. The extensions are detected via duck-typing (`typeof obj.recordMigration === "function"`) so other implementations are free to ignore runtime events. The port itself stays minimal.
- `EvolutionHistory` is RECONSTRUCTED from the registry's state — not a separate write-ahead log. `getEvolutionHistory` walks the version catalogue, attaches to each entry: migrationHistory (records where from OR to === entry version), compatibilityHistory (records where sourceVersion === entry version), certificationHistory (the artifact's carried `certification`). Entries sorted semver-ascending.
- `certifyArtifact` use-case issues a cert via the engine, then RE-REGISTERS the certified version with the new `certification` set (replace-in-place via `registerVersion`'s idempotent semantics). If the subject is not yet registered, the cert is still issued (certifications are valid independently of registration).
- `createGovernanceFramework()` factory wires a fresh `InMemoryGovernanceRegistry` + `DefaultCompatibilityEngine({registry})` + `DefaultMigrationEngine` + `DefaultCertificationEngine({clock})` sharing one clock (default `GovernanceZeroClock` at 0). Returns a `GovernanceFramework` bundle.
- Determinism: NO `Date.now()` / `Math.random()` anywhere (grep-verified — only JSDoc + comment text). All time via injected `RuntimeClock` or caller-supplied `at`. All ids via `hashSeed`. Identical inputs → byte-identical outputs (verified by running the inline sanity check twice with fresh framework instances and comparing JSON).
